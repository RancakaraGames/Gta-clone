# GTA Clone — Rancakara Games

Proyek pengujian dan pengembangan GTA Clone.

> **Status:** struktur awal proyek. APK dan data game belum disimpan di folder repository ini.

## Struktur folder

- `apk/` — tempat catatan dan tautan rilis APK.
- `game-data/` — tempat catatan data game (ZIP/OBB/data tambahan).
- `docs/` — panduan instalasi, pengujian, dan perubahan.
- `tools/` — skrip bantu proyek.

## Cara menambahkan file

1. Buka folder tujuan.
2. Pilih **Add file → Upload files** untuk file kecil yang didukung GitHub.
3. Untuk APK, gunakan **Releases → Attach binaries**.
4. Untuk ZIP data berukuran beberapa GB, gunakan penyimpanan file besar dan cantumkan tautannya di dokumentasi. Jangan masukkan file besar langsung ke Git biasa.

## Pengujian

- Catat perangkat dan versi Android.
- Catat apakah instalasi berhasil.
- Catat apakah game bisa dibuka dan apakah data terdeteksi.
- Jangan menganggap file aman hanya karena berhasil diunggah. Periksa sumber dan perilakunya sebelum dijalankan.

## Catatan keamanan

Gunakan hanya file yang memang berhak kamu gunakan. Jangan memasukkan password, token, atau kunci akses ke repository.
