# ROYAL PLAY

Project lobby game menggunakan Godot 4.7.2.

## Membuka proyek
1. Download repository sebagai ZIP.
2. Ekstrak ZIP.
3. Buka Godot Project Manager.
4. Pilih Import, lalu pilih file `project.godot`.
5. Jalankan proyek.

## Isi saat ini
- Lobby landscape 1280 x 720.
- Tampilan arcade ungu, biru, dan emas.
- Menu Domino, 2 Player Fishing, Bandar Qiu Qiu, dan Fish Royale.
- Tombol menu dan status interaksi dasar.

Catatan: ini adalah fondasi lobby. Modul gameplay online, server, akun, dan matchmaking belum termasuk dan harus dibuat terpisah.
