# ROYAL PLAY

Proyek lobby ROYAL PLAY untuk Godot 4.7.2.

## Membuka proyek
1. Download ZIP dari GitHub.
2. Ekstrak ZIP.
3. Buka Godot Project Manager.
4. Pilih Import dan pilih file project.godot.
5. Jalankan proyek.

## Struktur
- scenes/Lobby.tscn — seluruh susunan UI dibuat sebagai node Godot yang bisa diedit di Scene Editor.
- project.godot — pengaturan proyek.

Lobby menggunakan node Control, Panel, ColorRect, TextureRect, Label, dan Button. Tidak ada script pembangun UI. Kamu bisa mengubah posisi, ukuran, warna, teks, dan tombol langsung dari Inspector.

Menu yang disiapkan: Domino, 2 Player Fishing, Bandar Qiu Qiu, dan Fish Royale. Tidak ada game slot.

Catatan: ini fondasi tampilan lobby. Ilustrasi final dan sistem gameplay/multiplayer belum disertakan.
