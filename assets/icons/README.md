# ROYAL PLAY UI Icons

Setiap ikon disimpan sebagai file SVG terpisah agar mudah diubah ukuran dan warnanya.

- crown.svg — mahkota/avatar
- coin.svg — saldo/koin
- plus.svg — tombol tambah
- bonus.svg — bonus/hadiah
- news.svg — berita
- settings.svg — pengaturan
- home.svg — beranda
- trophy.svg — turnamen
- wallet.svg — dompet/top up
- mail.svg — pesan
- profile.svg — profil

Warna utama ikon: emas (#e8bd58). Semua SVG memakai viewBox 64 × 64 dan background transparan.

Catatan aset lain:
- assets/Royalplay.png adalah file logo/brand PNG yang sudah ada di project.
- assets/cards/*.svg adalah lima ilustrasi kartu game yang sudah ada. Ilustrasi kartu saat ini masih SVG, belum dikonversi menjadi PNG.
